# Wanco (わんこ大喧嘩)

C言語で書かれたシンプルなターミナルベースのタワーディフェンスゲームです。犬のような「わんこ」ユニットを出撃させて敵の基地を攻撃します。本プロジェクトは、標準的なターミナルで動作するゲームを作成するための基盤として機能します。

```

 ^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^




                                                                ------- =======
                                                                 wanco  |noppo|
                                                                ------- =======
```

## 遊び方

右側にある自分の基地からユニットを出撃させ、左側にある敵の基地を破壊します。選択キーと出撃キーを使って、ステータスの異なる様々な「わんこ」ユニットを生成します。

### 操作方法

- **Tab**: ユニットの種類の選択
- **Space**: 選択したユニットの出撃
- **ESC**: ゲームの終了

## はじめに

### 動作環境

- POSIX準拠のシステム（例: Linux, macOS）
- GCC または互換性のあるCコンパイラ

### インストールと実行

リポジトリをクローンし、メインのゲームファイルをコンパイルして実行します。

```sh
gcc wanco.c && ./a.out
```

## 同梱されているゲームとユーティリティ

本リポジトリには、同じライブラリコンポーネントを使用して作成された、いくつかの小さなゲームやツールも同梱されています。

- **Nyanko Kawakudari (にゃんこかわくだり)**: シンプルな障害物回避ゲーム。
    ```sh
    gcc kawakudari.c && ./a.out
    ```

- **AtoZ Hayauchi Game (AtoZはやうちゲーム)**: タイピングの早打ちゲーム。
    ```sh
    gcc a2z.c && ./a.out
    ```

- **Keycode Check Tool (キーコードチェックツール)**: キーコードを表示するユーティリティ。
    ```sh
    gcc keycheck.c && ./a.out
    ```

## プロジェクト構成

プロジェクトは、メインのゲームロジックと再利用可能なライブラリ群に分かれています。

### メインゲームファイル

- [wanco.c](wanco.c): メインのゲームループと初期化処理。
- [wanco.h](wanco.h): コアとなるゲーム関数とオブジェクトの定義。
- [wanco_res.h](wanco_res.h): すべてのゲームエンティティ用のアスキーアートリソース。

### ライブラリファイル

- [lib/Screen.h](lib/Screen.h): ターミナルの画面バッファとレンダリングを処理。
- [lib/Image.h](lib/Image.h): アスキーアート画像の構造体を定義。
- [lib/Sprite.h](lib/Sprite.h): スプライト、その位置、および画像を管理。
- [lib/Keyboard.h](lib/Keyboard.h): ノンブロッキングなキーボード入力を処理。
- [lib/Button.h](lib/Button.h): ボタンのUI要素を実装。
- [lib/ButtonManager.h](lib/ButtonManager.h): 複数のボタンを管理。
- [lib/Mover.h](lib/Mover.h): スプライトの移動パターン（落下など）のロジックを定義。
- [lib/MoverManager.h](lib/MoverManager.h): ゲーム内のすべてのアクティブなMover（移動体）を管理。
